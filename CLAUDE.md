# CLAUDE.md — buckley.ca

Personal static site: **Astro** (`output: 'static'`) → **Cloudflare Pages** (Git integration, no
adapter). See [README.md](README.md) for the full script list.

## Stack & commands

- Package manager: **npm** (not pnpm). Node **≥ 24** (see `.node-version`).
- Toolchain: **Vite+** (`vp`). `vp <name>` is a Vite+ built-in; `vp run <name>` (alias `vpr`) runs the
  `package.json` script of that name. npm scripts still work and are what CI uses.
- `vp run dev` · `vp run build` (→ `dist/`) · `vp run preview`.
- Before calling a change done: `vp check` (Oxfmt + Oxlint + TS), `vp run check` (astro check),
  `vp run test` (Playwright), `vp run lint` (also covers `.astro` via Prettier).
- `vp test` is Vitest, not Playwright — `tests/` is excluded in `vite.config.ts`, so it reports no
  tests. Never use it to validate the e2e suite.
- Pre-commit hook: `.vite-hooks/pre-commit` runs `vp staged` (`vp check --fix`).
- `AGENTS.md` between the `VITE PLUS` markers is generated by `vp config` — don't hand-edit it.

## Conventions

- Keep it a simple static site — no SSR/CMS, minimal dependencies; anything fancier must earn it.
- Git (commits, branches, PRs) follows the global `~/.claude/CLAUDE.md`.
